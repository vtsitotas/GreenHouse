# Παρουσίαση προϊόντος — GreenHouse

`GreenHouse_Parousiasi.pptx` — παρουσίαση ~10 λεπτών στα ελληνικά: 17 κύριες
διαφάνειες συν 3 παραρτήματα. Κάθε διαφάνεια έχει σημειώσεις ομιλητή με
ενδεικτική χρονομέτρηση.

Το περιεχόμενο είναι γραμμένο ως **παρουσίαση προϊόντος**: πρόβλημα και αγορά,
πώς δουλεύει το σύστημα, τι το ξεχωρίζει, πού πάει (θερμοκήπιο → φυτώριο →
χωράφι) και ποια η γενικότερη αξία της πλατφόρμας. Η τρέχουσα κατάσταση του
έργου βρίσκεται στα παραρτήματα, όχι στο κυρίως μέρος.

## Επαναδημιουργία

```bash
npm install pptxgenjs react-icons react react-dom sharp
node icons.js          # παράγει τα assets/icons/*.png από το react-icons
node deck.js           # γράφει το GreenHouse_Parousiasi.pptx
```

- `deck.js` — ο γεννήτορας της παρουσίασης (όλο το κείμενο και η διάταξη).
- `icons.js` — παράγει τα εικονίδια σε τρεις αποχρώσεις (λευκό / σκούρο / χρυσό).
- `crop.js` — τεκμηριώνει πώς κόπηκαν τα στιγμιότυπα του `assets/mesh1..4.png`
  από τις αρχικές λήψεις οθόνης του κινητού (αφαίρεση μπάρας συστήματος,
  μπάρας πλοήγησης και υπομνήματος). Χρειάζεται τα πρωτότυπα αρχεία για να
  ξανατρέξει· τα κομμένα αποτελέσματα είναι ήδη στο `assets/`.

## Πηγές των στατιστικών

- Θερμοκηπιακές εκτάσεις: ΕΛΣΤΑΤ, ετήσια γεωργική έρευνα (στοιχεία 2018).
- Άρδευση ως ποσοστό κατανάλωσης νερού: Latinopoulos, *Valuation and pricing
  of irrigation water*, Global NEST Journal.
- Τα ενεργειακά νούμερα προκύπτουν από τις σταθερές λειτουργίας του κόμβου —
  δες [`docs/SENSOR_NODE_POWER_AND_SOLAR.md`](../SENSOR_NODE_POWER_AND_SOLAR.md).
